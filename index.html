MATERI 1 — APA ITU MODULE?

Module adalah file Python yang berisi kode yang bisa kita gunakan kembali.

📦 Analogi: Bayangkan module seperti sebuah kotak alat (toolbox). Di dalam kotak tersebut terdapat berbagai macam alat (function, variable) yang siap kamu pakai kapan saja.

hitung.py
def tambah(a, b):
    return a + b

File hitung.py di atas adalah sebuah module yang bisa digunakan oleh program lain!

MATERI 2 — FILE PYTHON

File kode Python selalu disimpan dengan ekstensi .py.

Contoh nama file Python:

  • hitung.py
  • game.py
  • tools.py

Setiap file berkahiran .py yang kamu buat secara otomatis bisa dijadikan sebagai module!

MATERI 3 — MEMBUAT FUNCTION

Kata kunci def digunakan untuk membuat function (perintah tersimpan).

def sapa():
    print("Halo!")

# Cara memanggil function:
sapa()

Output: Halo!

MATERI 4 — MEMBUAT MODULE SENDIRI

Misalnya kita memiliki dua buah file di folder yang sama:

tools.py (Module)
def sapa():
    print("Halo dari module!")
main.py (Program Utama)
import tools

tools.sapa()

Output: Halo dari module!

MATERI 5 — IMPORT MODULE SENDIRI

Perhatikan cara kerjanya:

1. import tools → "Kita ingin mengambil module bernama tools."

2. tools.sapa() → "Kita menjalankan function sapa() yang ada di dalam module tools."

tools.py ➡️ import tools ➡️ main.py ➡️ tools.sapa()

MATERI 6 — MODULE DENGAN VARIABLE

Module tidak hanya berisi function, tetapi juga bisa menyimpan variable!

data.py
nama = "Budi"
umur = 13
main.py
import data

print(data.nama)
print(data.umur)

MATERI 7 — FUNCTION DENGAN PARAMETER

hitung.py
def tambah(a, b):
    return a + b
main.py
import hitung

hasil = hitung.tambah(5, 3)
print(hasil)

Output: 8

MATERI 8 — MODULE + IF

cek.py
def cek_nilai(nilai):
    if nilai >= 70:
        print("Lulus")
main.py
import cek

cek.cek_nilai(80)

Output: Lulus

MATERI 9 — MODULE + IF ELSE

cek.py
def cek_nilai(nilai):
    if nilai >= 70:
        print("Lulus")
    else:
        print("Belum lulus")
main.py
import cek

cek.cek_nilai(60)

Output: Belum lulus

MATERI 10 — MODULE + WHILE

game.py
def hitung():
    angka = 1
    while angka <= 3:
        print(angka)
        angka = angka + 1
main.py
import game

game.hitung()

Output:
1
2
3
